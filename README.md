# 📄 AI Resume Analyzer & Document Verification System

A web-based tool that combines resume analysis with document verification.

## About

The system reads resume data, identifies skills, and helps with document review and validation.

## Features

- Reads and extracts data from resumes
- Spots skills mentioned in a resume
- Supports document review and validation

## Tech Stack

- **Languages:** Python, JavaScript
- **Front end:** HTML, CSS
- **Approach:** AI/ML
